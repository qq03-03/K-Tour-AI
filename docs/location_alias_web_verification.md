# P001~P030 다국어 장소 별칭 인터넷 검증

- 검증일: 2026-08-05
- 목적: 별칭으로 실제 프로젝트 장소가 검색되는지 확인하고, 공식 표기와 검색용 임시 표기를 구분한다.
- 판정 기준:
  - `공식 다국어`: 공공기관·관광기관·시설 공식 사이트에서 외국어 표기 확인
  - `장소 확인/외국어 보조`: 장소는 공식 자료로 확인했지만 일부 외국어는 로마자 또는 설명형 검색 별칭
  - `데이터 라벨`: 실제 지역은 확인되지만 프로젝트가 붙인 촬영지 단위 이름으로, 독립 관광지 공식 명칭은 아님
